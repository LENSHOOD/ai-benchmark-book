# 变更记录

## v0.4.0 · 2026-09-10

- 全面改写 16 章正文和读者入口：先讲结论与具体场景，再解释专业术语。
- 长句拆分，一段只讲一件事；抽象名词尽量改成读者能执行、观察和复查的动作。
- 为 Harness、Skill、Grader、构念、效度、Episode、Veto、复证等核心术语补上直白中文解释，同时保留英文锚点便于检索。
- 首页、导读、实验课、Radar 和方法附录同步改写，事实数字、引用、代码接口和历史评审记录保持不变。
- 新增白话文风回归门禁和 v0.4.0 源文件哈希清单。

## v0.3.2 · 2026-08-29

- 首次以独立公开仓库发布，并启用 GitHub Pages 自动构建与部署。
- Pages 与质量工作流均显式固定 Node.js 22 和 Python 3.12，避免部署门禁依赖 runner 的隐式 Python 版本。
- 将数学渲染依赖链中的 `@xmldom/xmldom` 从已弃用的 0.9.10 覆盖到 0.9.12，避免在公开构建中继续安装已知问题版本。
- 公开审计材料移除本机绝对路径；带有 `file:///Users/...` 链接的历史 PDF 构建产物不进入发布提交，Markdown 与 HTML 审查报告保留。
- 源码清单排除所有案例目录中的运行产物，并新增内部锚点负向回归、结果不可覆盖、状态幂等和 Pages base path 门禁。
- 新增 v0.3.2 源文件哈希清单，v0.3.0 与 v0.3.1 清单继续作为不可覆盖的历史基线。

## v0.3.1 · 2026-08-28

- 修复第 9 章到 Skill 实证小节、阅读指南到首页成熟度声明的两处失效 fragment。
- 首页成熟度警示升级为正式二级标题，既可深链，也保留醒目的 beta 边界提示。
- 内容门禁开始按 VitePress 1.6.4 的标题 slug 与重复标题规则验证全部内部锚点，不再只确认目标页面存在。
- 新增不可覆盖的 v0.3.1 源文件哈希清单；v0.3.0 清单保留为历史基线。

## v0.3.0 · 2026-08-28

- 将读者可见定位统一为“体系化方法手册与实践课程（beta）”，首页公开来源核验状态和仍未覆盖的横切主题。
- 补齐全部具名 grader 失败类别的直接语义测试，并让配对任务数、空集合防线和诊断权重进入回归测试。
- 将渲染门禁扩展到全部 HTML 页面；补齐两章决策问题、关键框架证据标签、案例章方法回链与框架总览入链。
- 在 Agent、Harness、电商长程与硬件工具基座章节加入经一手论文核验的实测数字和外推边界。
- 为 arXiv 来源增加批量元数据核验与联网题名比对；登记、可达与元数据核验继续保持不同状态。
- 更正 v0.2 裁决账本中 P1-22 的漏修申报，并加入内容门禁防止公开方法页再次泄露内部采集过程。

## v0.2.0 · 2026-08-27

- 修正 SWE-Skills-Bench、SupChain-Bench 与 RetailBench 的错误或非规范 arXiv 条目；移除失效的 RetailBench 站点链接。
- 为统计附录启用 MathJax 渲染并新增构建产物残留检查。
- 将被测系统与 grader/预算/协议分开，补充效度理论争议、BFCL/API-Bank 版本边界和能力执照的作者提案属性。
- 重写双案例的最小实现：策略只能看到公开任务视图；grader 检查终态；受控故障、幂等恢复、任务级配对和审计 manifest 进入运行器。
- 扩充 Skill 章节的文献实测数字，新增框架总览、练习评分支架与更强内容门禁。
- 澄清 Radar 的 `maturity` 只是当前编辑标签，来源账本中的 `unverified` 不是已核验声明。

## v0.1.0 · 2026-08-23

- 首次形成 16 章、双合成案例、70 项 Benchmark Radar、121 条来源账本和 VitePress 发布骨架。

版本号描述本书交付物，不代表其中所有外部项目都在同一天完成复核。动态项目的实际状态以其一手来源及随书账本字段为准。这里的“beta”表示结构、案例和自动门禁可供试读与课程使用，不表示所有论断已完成学术级证据审定。
