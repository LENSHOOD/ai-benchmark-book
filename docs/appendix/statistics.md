# 统计速查

本附录不替代统计教材，目标是让实践者避免最常见的解释错误。

## 先明确观测层级

一个 trial 嵌套在系统—任务组合中，任务又可能嵌套在领域、客户、设备或模板中。不能把全部 trial 当独立样本。先画数据生成层级，再选择区间或模型。

## 二元成功率

若 $y_i \in \{0,1\}$，成功率为：

$$
\hat p = \frac{1}{n}\sum_{i=1}^{n}y_i
$$

始终给分子、分母和区间。任务很少时不要依赖正态近似；Wilson 区间或任务级 bootstrap 更稳妥。

## 配对差值

候选 A、B 在相同任务运行，定义 $d_i = y_{i,B}-y_{i,A}$。报告平均差值、胜/负/平和区间。配对能消除大量任务难度方差。

## 两层 Bootstrap

1. 有放回重采样任务；
2. 对抽中的每个任务，有放回重采样 trial；
3. 计算目标统计量；
4. 重复足够次数，取分位区间。

若生产失败有共同原因，按事件批次、客户或时间块重采样，而非假设 trial 独立。

## pass@k 与 pass^k

在独立且单次成功率为 $p$ 的简化条件下：

$$
pass@k = 1-(1-p)^k
$$

$$
pass^k = p^k
$$

前者随着尝试数提高，适合候选搜索；后者随连续服务次数下降，适合可靠性直觉。真实运行通常不独立，因此同时报告经验连续失败和共同故障。

## 混合效应思路

二元任务可用混合效应 logistic 模型：

```text
logit(P(success)) ~ model + harness + skill
                  + model:harness + model:skill + harness:skill
                  + (1 | task) + (1 | domain)
```

当数据不足以支持复杂模型，优先报告逐题结果、配对差值和分层区间，不要用复杂公式制造确定感。

## 最小实际重要差异

在看结果前定义多大变化值得发布。例如 1 个百分点可能对百万级高频流程重要，对 20 题研究集则可能小于测量误差。把差异转成成功数量、人工分钟、成本或事故风险。

## 多重比较

大量模型、任务切片和指标会增加偶然“显著”结果。预先指定主要比较；探索结果标注探索性；报告全部运行和负结果；必要时控制错误发现率。不要只挑获胜切片。

## 推荐最小报告

- 系统、suite、grader 与预算版本；
- 任务数、trial 数、缺失与环境错误；
- 严格成功、veto、主要诊断指标；
- 任务级配对差值和区间；
- 频率集/风险集与关键切片；
- 成本、尾延迟、人工接管；
- 预注册偏离、已知限制和原始逐题结果。
