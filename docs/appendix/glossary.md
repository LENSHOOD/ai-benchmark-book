# 术语表

本表给出本书采用的工作定义。术语在不同社区可能有其他用法，设计文档应主动声明口径。

| 术语 | 工作定义 |
|---|---|
| Eval | 为判断 AI 系统表现而收集证据的具体活动或测试。比 benchmark 更宽。 |
| Evaluation | 评估活动总称，包括离线、在线、人工、自动、生产监控和红队。 |
| Benchmark | 标准化任务、协议与指标的组合，用于相对一致条件下比较。 |
| Leaderboard | 选择部分 benchmark 结果进行排序的展示层。 |
| Suite | 多个任务或 eval 的版本化集合。 |
| 构念（construct） | 希望根据行为证据推断的潜在能力或属性。 |
| 操作化（operationalization） | 将抽象构念转成可观察任务、行为和指标。 |
| 效度（validity） | 某种分数解释在指定用途和条件下是否得到充分证据支持。 |
| 信度（reliability） | 在合理重复与抽样条件下，测量结果的一致程度。 |
| 内容效度 | 任务样本是否覆盖构念需要代表的内容范围。 |
| 生态效度 | 评测条件与目标部署情境的关系。不是“越真实越好”的单维尺度。 |
| 构念无关方差 | 与目标能力无关的因素改变分数，例如格式、语言噪声或环境故障。 |
| 构念代表不足 | 题集漏掉目标能力的重要部分，尤其是边界、风险和异常。 |
| 任务宇宙（task universe） | 目标部署中所有相关任务情形的概念总体。 |
| 项目（item） | 从任务宇宙抽取并写成可执行规范的一条有限样本。 |
| Episode | Agent 从初始状态到成功、失败、升级或超时的一次完整交互。 |
| Task Spec | 任务的机器/人可读契约，含状态、输入、动作、目标、禁止、预算和 grader。 |
| Grader / Scorer | 将系统输出、轨迹或环境状态转成评测结果的机制。 |
| Verifier | 通常指能确定性验证状态、约束或执行结果的 grader。 |
| Rubric | 将开放质量拆成维度、等级与行为锚点的评分规则。 |
| LLM-as-a-Judge | 使用语言模型评价候选输出的方法。需要独立校准和安全隔离。 |
| Strict success | 全部关键断言成立、禁止状态未发生且升级正确的任务通过。 |
| Veto | 不能被普通质量分抵消的严重失败或禁止行为。 |
| Partial credit | 用于诊断的部分完成分，不应自动等同于业务价值。 |
| Agent | 能多轮观察、调用工具、改变环境、处理反馈并决定停止的系统。 |
| Agent harness | 控制 Agent 上下文、工具、记忆、计划、验证、恢复、权限与终止的系统层。 |
| Evaluation harness | 装载任务、运行系统、收集轨迹、评分和聚合的测量基础设施。 |
| Skill / Plugin | 聚合领域流程、知识、示例、脚本或工具连接的版本化能力依赖。 |
| Environment | 被测系统观察与改变的有状态世界，包括工具、数据、权限和时间。 |
| Sandbox | 隔离、可重置、通常可回滚的执行环境。 |
| Digital twin | 为目标构念保留关键状态、行为与损失的业务或工程环境模型。 |
| Trace / Trajectory | Agent 在 episode 中的观察、调用、状态与错误记录。 |
| Tool calling | 选择工具并生成参数；只是业务完成的一部分。 |
| pass@k | k 次尝试至少一次成功的概率/估计，偏向搜索和候选生成。 |
| pass^k | 连续 k 次均成功的可靠性概念，偏向重复服务。 |
| Trial | 同一系统—任务组合的一次运行。 |
| Pairing | 让候选运行相同任务/状态，再分析任务级差值。 |
| Ablation | 移除或替换某组件，估计其边际作用。 |
| Factorial design | 交叉 Model、Harness、Skill 等因素，估计主效应与交互。 |
| Interaction | 一个组件的效果取决于另一个组件或任务条件。 |
| Bootstrap | 通过重采样估计统计量不确定性的方法。 |
| Mixed-effects model | 同时建模固定因素与任务、领域等随机差异的统计模型。 |
| Calibration | 预测置信与真实正确概率的对应程度；也指评测器与专家 gold 的校准。 |
| Contamination | 题目、答案、模板、衍生数据或针对性反馈进入训练/开发过程。 |
| Saturation | 目标系统接近天花板，题集区分信息下降。 |
| Goodhart 风险 | 指标成为优化目标后，作为目标现象代理的质量下降。 |
| Anchor item | 跨版本保留、用于连接测量尺度的受保护项目。 |
| Qualification set | 对研发隐藏、用于发布或授权门禁的任务集合。 |
| Risk set | 按严重性、不可逆性和攻击面抽样的门禁集合。 |
| Shadow mode | 读取生产输入但不执行真实写入，用于上线前对照。 |
| Canary | 在受限流量、权限和回滚条件下进行的真实部署验证。 |
| Recertification | 组件、任务、政策或环境变化后重新证明授权条件。 |
| Capability license | 记录数字员工任务范围、权限、版本、证据、到期和复证条件的治理对象。 |
| FDE | Forward-Deployed Engineer；在一线共同识别问题、重构流程并将 AI 系统落入真实业务的人。 |
