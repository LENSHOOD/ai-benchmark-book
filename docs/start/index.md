# 阅读指南

这本书只看一个毕业标准：你能不能为一个真实 AI 系统，从零做出一套能运行、能解释、还能持续维护的 benchmark。背下 MMLU、SWE-bench 或某张排行榜上的数字，不算学会。

## 三条阅读路径

**第一次系统接触评测**：从头读。每章先看开篇问题，再做最后的练习。统计公式暂时看不懂，可以先跳过。

**正在选模型、Agent 或 Skill**：先读第 3、4、7–11 章，再用模板做一个小型同题对比实验。

**正在做 FDE 或数字员工**：先读第 4、8、11、12 章，再选第 13 或第 14 章当项目蓝图。最后用第 15 章决定给多少权限、什么时候重新验证。

## 全书共用的学习结构

每章先提出一个你真的会遇到的决定，再用概念、反例、案例、检查单、练习和来源来回答。案例章会带你从头走一遍；概念章则帮助你理解为什么要这样做。

## 证据标签

为了不把事实、作者判断和未来猜测混在一起，本书给关键段落加了四种标签：

- **来源事实**：可以回到论文、官方代码、标准或原始项目核对；
- **综合判断**：作者把多份证据放在一起后得到的解释；
- **实践建议**：作者建议你怎样设计和管理；
- **未来推测**：可能发生，但还不是稳定事实。
