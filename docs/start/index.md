# 阅读指南

这本书的毕业标准很简单：你能否为一个真实 AI 系统，从零建成一套可运行、可解释、可维护的 benchmark。记住 MMLU、SWE-bench 或某张排行榜上的数字，不算毕业。

## 三条阅读路径

**第一次系统接触评测**：按章节顺序阅读。每章先抓住开篇问题，再完成“带走的问题”。遇到统计公式可以先跳过附录。

**正在做模型、Agent 或 Skill 选型**：先读第 3、4、7–11 章，再使用模板建立自己的小型配对实验。

**正在做 FDE 或数字员工**：先读第 4、8、11、12 章，然后选择第 13 或第 14 章作为项目蓝图，最后读第 15 章决定授权与复证。

## 全书共用的学习结构

每章都从一个决策问题出发，并在适合的位置使用概念、反例、案例、检查单、练习和来源。它们是全书统一的学习元素，不是每章必须机械重复的六个同名标题。案例章会把走读和交付物放在主线中；概念章则更强调定义、反例与来源。

## 证据标签

对容易混淆的关键段落，本书使用四种可见口径；未加容器的过渡叙事仍需由紧邻引文或章节来源支持：

- **来源事实**：能追溯到论文、官方代码、标准或原始项目；
- **综合判断**：由多个证据簇推导出的解释；
- **实践建议**：作者对设计和治理的规范性选择；
- **未来推测**：尚未成为稳定事实的方向判断。
