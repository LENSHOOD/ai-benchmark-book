# Benchmark Charter 模板

## 1. 决策与受众

- 这个 benchmark 要支持什么决策：模型选型 / 能力研发 / 发布门禁 / 上岗授权 / 持续监控？
- 谁将依据分数采取行动？错误结论的代价是什么？
- 明确不支持哪些解释和用途。

## 2. 构念声明

- 构念名称与操作性定义：
- 构念包含的能力或行为：
- 明确排除的相邻能力：
- 预期与哪些外部指标收敛，和哪些指标应保持区分：
- 分数的预期解释：

## 3. 任务宇宙与抽样

- 目标任务总体：
- 任务来源：生产、专家创作、日志回放、公开数据、参数化合成：
- 正常/边界/异常/对抗/安全任务比例：
- 频率加权集与风险加权集如何分别构建：
- 实体、时间、模板和组织单位的切分规则：
- 人类专家是否能完成、条件和时限是什么：

## 4. 被测系统边界

- Model ID、版本、推理预算和采样参数：
- Agent Harness 名称、commit、工具、上下文、重试和终止：
- Skill/Plugin 名称、版本、依赖与生效期：
- 权限、网络、文件、凭据和外部服务：
- 人工可以在何时介入：

## 5. 环境与预算

- 初始状态、虚拟时钟、随机种子和重置方法：
- token、调用、墙钟、费用、并发和计算预算：
- 环境故障如何与 Agent 失败区分：
- 哪些副作用必须检查和回滚：

## 6. Grader 设计

- 确定性终态断言：
- 过程/政策断言：
- 禁止状态与安全 veto：
- 开放式产物 rubric：
- LLM judge 型号、提示、盲评和顺序随机规则：
- 人工 gold、分歧仲裁和 grader 校准方案：

## 7. 统计计划（预注册）

- 主指标和次指标：
- trial 数、seed 和停止规则：
- 任务级配对方式：
- 置信/可信区间和效应量：
- 多重比较处理：
- 缺失运行、超时和基础设施失败处理：
- 切片与公平性分析：

## 8. 发布与治理

- dev / calibration / qualification / incident-regression / canary 分割：
- 版本、锚题、滚动更新和退役规则：
- 污染检测、canary string 和提交限额：
- 结果披露、原始轨迹、许可证和隐私策略：
- owner、复审周期和争议申诉流程：
