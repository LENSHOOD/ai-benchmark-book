# Rubric 与 Judge Card 模板

## Rubric

| 维度 | 可观察定义 | 等级锚点 | 权重 | 是否 veto | 所需证据 |
|---|---|---|---:|---|---|
| 正确性 | 与输入事实、规则和终态一致 | 0/1 或明确 1–5 行为锚点 |  |  |  |
| 完整性 | 覆盖规定的关键要求 |  |  |  |  |
| 流程合规 | 必要步骤、审批和权限均满足 |  |  | 是/否 |  |
| 副作用 | 没有不允许的状态变化 |  |  | 是 |  |

## Judge Card

- Judge 类型：规则 / 领域算法 / 人工 / LLM / 组合
- 型号、版本、prompt 哈希、temperature、输出 schema：
- 是否看到候选身份、顺序或 reference answer：
- 盲化、答案顺序随机和多 judge 规则：
- 校准集来源、规模和更新日期：
- 对人工 gold 的 accuracy、precision、recall、specificity：
- 顺序一致率、重复一致率、跨 judge 一致率：
- 已知偏差：长度、风格、自偏好、立场、拒绝倾向：
- 分歧仲裁与人工升级阈值：
- Judge 版本变化后的回溯重评分方案：
