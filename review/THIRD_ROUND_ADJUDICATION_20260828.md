# 第三轮评审裁决与修订验收

## 执行结论

第三轮评审的主体判断合理，尤其是审计申报失实、具名失败类别缺少直接测试、读者定位不透明、案例叙述与实际运行分布不一致、渲染门禁只覆盖单页，以及框架总览缺少正文入链。这些问题均已按可复核验收条件修复。

评审对版本基线和 `dist/` 的风险方向有价值，但局部事实不适用于作者工作区：项目当时位于另一个父 Git 工作区的未跟踪目录中；`docs/.vitepress/dist/` 是被 `.gitignore` 排除的本地构建产物，评审不能据此断言它“已提交”。本轮未替用户执行父仓库提交，改用可复核源文件哈希清单建立 v0.3 基线。

## R3 裁决

| 条目 | 裁决 | 修订与证据 | 剩余边界 |
|---|---|---|---|
| R3-0 方法页泄漏与申报失实 | 采纳并关闭 | 删除个人化采集过程；更正上一轮裁决 P1-22；内容门禁禁止“用户最初提供/验证码阻断” | 审计状态仍需以后续文件实况为准 |
| R3-1 failure class 测试 | 采纳并关闭 | 测试由 11 增至 16；直接覆盖 `environment_error`、`veto`、`insufficient_evidence`、`target_state`、`missing_evidence`、`escalation`、`none`，并覆盖禁止终态、空集合、诊断权重和动态任务交集 | 不采用通用 mutation-score 百分比 |
| R3-2 定位声明 | 采纳并关闭 | README、首页、变更记录统一为“体系化方法手册与实践课程（v0.3 beta）”；首页公开 53/140 已核验与横切主题缺口 | beta 不是“权威教材”声明 |
| R3-3 证据标签铺开 | 调整采纳 | 在历史分期、八层系统、企业四层、FDE 十阶段、能力执照、五级授权、十二维审计和四组经验数字首次出现处标注事实/综合/建议 | 不设每章数量 KPI；仍需逐步提高全部历史主张的 claim-level 引文 |
| R3-4 两章缺决策问题 | 采纳并关闭 | 第 13、14 章补“本章问题”；门禁要求 16/16 章均存在 | — |
| R3-5 四章经验数字 | 采纳并关闭 | 第 8、9、13、14 章分别加入 Terminal-Bench、SkillsBench、MerchantBench/RetailBench、PHMForge 一手数字与边界句 | 不把论文摘要数字当作企业基线 |
| R3-6 来源账本 | 采纳并显著推进 | 51 条 arXiv 记录全部经官方 API 核验题名、作者、版本和年份；`--online` 检查 ID 存在性与题名；账本现 53 `verified_primary` / 87 `unverified` | 非 arXiv 记录仍需按引用风险逐批核验；论断支持关系不等于元数据正确 |
| R3-7 版本基线 | 调整采纳 | 确认父 Git 根确实存在但项目未跟踪；不越权提交，新增 `release/v0.3.0-source.sha256` 与 CI 校验 | 用户决定何时把项目纳入父仓库 |

## N3 裁决

| 条目 | 裁决 | 修订与证据 |
|---|---|---|
| N3-2 第 13 章运行描述失真 | 采纳并关闭 | 明确最强规则策略当前失败全来自环境故障、veto 为零，正确/危险计划均为教学规则预设，不再暗示测得真实组件效应 |
| N3-3 登记即豁免 | 采纳并关闭主要通道 | 联网维护门禁要求所有 arXiv ID 被官方 API 返回且题名一致；假 ID 或错题名会失败 |
| N3-4 单页公式门禁 | 采纳并关闭 | `check_rendered.py` 遍历构建目录全部 HTML；任一页面出现裸 TeX 标记即失败，统计页另要求 MathJax 输出 |
| N3-5 框架总览孤儿 | 采纳并关闭 | 十个框架宿主章均回链总览；两个案例章分别回链任务宇宙、环境和 grader 方法；门禁要求至少十个宿主章入链 |
| N3-6 dist 与 ignore 冲突 | 不采纳事实结论，采纳文档澄清 | 父仓库确认该路径被忽略；README/CONTRIBUTING 明确 dist 是 CI 可重建产物，不属于源文件基线 |

## 额外发现与修复

第一次完整联网巡检对 51 个 arXiv ID/题名全部匹配，同时发现旧 `SWE-bench Verified guide` URL 返回 404。正文和账本已切换到官方规范页面 `https://www.swebench.com/verified.html`，并按新 canonical URL 生成新的稳定 source ID。PHMForge 账本和 Radar 也从旧快照更新到 v3 的 99 场景、8 类资产与 39 个 MCP 工具。

## 验收标准

- 内容：16/16 章有决策问题；框架总览至少由 10 个宿主章回链；关键作者框架和经验数字有可见证据口径。
- 代码：16 个单元测试覆盖所有具名失败类别、答案隔离、状态 veto、权重、空集合、任务级配对、故障方差和审计字段。
- 来源：140 个正文 URL 全登记；51/51 arXiv ID 与题名通过一手 API；53 条 `verified_primary`，87 条 `unverified`。
- 发布：VitePress production build、全部页面 TeX 残留检查、统计页 MathJax 检查和源文件哈希基线均必须通过。

## 当前发布判断

**内部课程与 public beta：无保留 Go。** 第三轮列出的 beta 前必修和两项强烈建议已经完成。

**“所有来源与重要论断均达到学术级核验的 v1.0 权威教材”：仍是 No-Go。** 主要残余是 87 条非 arXiv/项目来源尚未逐条核验、历史和理论主张的 claim-level 映射仍不完整，以及公平、数据劳动、在线人因等横切主题没有形成与主干同等深度。工程门禁进步不能替代这些内容证据。
