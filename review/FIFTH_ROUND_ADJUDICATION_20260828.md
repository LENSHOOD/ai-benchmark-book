# 第五轮补丁验收裁决与评审收口

## 结论

第五轮备忘对 v0.3.1-beta 的验收结论合理，且与本轮独立复核一致：第四轮 N4-1 的两处锚点、fragment 门禁、历史与当前版本清单、基线指向及端到端发布门禁均符合申报；没有发现新的事实、内容、工程或发布缺陷。

因此本轮不修改书稿正文、案例实现、来源账本或质量门禁，也不进行无实质内容变化的版本升级。当前发布版本继续是 v0.3.1-beta；public beta 维持无保留 Go。第五轮作为补丁验收终点收口，后续只有出现实质源码、证据或协议变更时才重新启动评审。

第五轮表头使用“4/4 项裁决”，逐项表格则展开为多个可观察检查面。这只是统计粒度差异，不影响任何验收结论，也不需要修改书稿。

## 验证记录

- 内容门禁：29 个 Markdown 文件、16 章、36,571 个章节汉字、70 条 Radar 记录、140 条来源与 140 个已登记外链，错误为零。
- 来源门禁：140 条记录，53 条 `verified_primary`，错误为零。
- 完整性门禁：v0.3.1 的 95 个源文件全部通过哈希校验。
- 示例测试：16/16 通过。
- 发布构建：VitePress 1.6.4 production build 通过；35 个 HTML 页面通过渲染数学检查。
- 负向灵敏度：隔离副本将合法 fragment 替换为 `#不存在的第五轮验收锚点` 后，检查脚本退出码为 1，并正确识别失效锚点。

首次负向测试夹具漏拷了 `check_book.py` 导入的 `examples` 包，因而在门禁执行前报 `ModuleNotFoundError`。补齐 `docs`、`scripts`、`examples`、`data` 和 `templates` 后复测通过。该事件已作为测试夹具错误记录，不被误报为产品缺陷。

## 版本与修改边界

本轮唯一持久化产物是本裁决账本以及项目内部的计划/进度记录；它们不属于 v0.3.1 发布源文件清单。正文、数据、模板、示例、脚本、依赖和发布配置均未因第五轮验收而改变，因此：

1. 不升级到 v0.3.2；
2. 不重写 `release/v0.3.1-source.sha256`；
3. 保留 `release/v0.3.0-source.sha256` 作为历史基线；
4. 不把 v1.0 增强项混入已通过的 beta 补丁。

## 最终发布判断与后续触发条件

- **内部课程：Go。**
- **公开 beta：无保留 Go。**
- **学术级权威 v1.0：No-Go，残余不变。**

v1.0 仍需分批核验 87 条非 arXiv 来源，补齐关键历史/理论主张的 claim-level 证据映射，并深化公平、数据劳动与在线人因评测。英文索引、每章元信息、axe/pa11y、Radar owner 和混合效应完整代码继续作为增强项，而不是当前 beta 的发布阻断。

以下任一条件出现时重新启动评审：正文或案例协议发生实质变化；来源账本状态或核心引文变化；grader、统计或发布门禁变化；依赖升级改变渲染/构建行为；新增公开发布承诺。仅有排版、裁决记录或无语义元数据调整时，可按风险决定是否只运行现有回归门禁。
