# 外部评审裁决与修订账本

## 结论

外部评审不是“全对”或“全错”。它对参考实现的因果污染、伪重复、错链、公式发布故障、来源账本与教学支架的诊断，明显强于原独立审查，值得采纳。它把“篇幅、图数、数字数、mutation score”等建议升级为通用 P0 门槛，则把本书自己反对的 Goodhart 问题带进了修订过程；“先在项目目录 `git init`”还忽略了项目位于现有父仓库且目前只是未跟踪子目录这一事实。

本轮采用三种裁决：**采纳**表示问题和建议方向均成立；**调整采纳**表示问题成立，但替换了任意阈值或不合适的修复方式；**不采纳/延期**表示事实基础不足、与用户已确认边界冲突，或属于后续版本扩展而非当前正确性修复。

## P0 裁决

| 编号 | 裁决 | 本轮处理 | 剩余边界 |
|---|---|---|---|
| P0-1 体量不足 | 调整采纳 | 承认部分章节偏提纲化，新增框架总览、案例实现说明、Lab 和逐章答案；保留 10 万字以内的用户约束 | 不接受 18–22 万字作为发布硬门槛；横切专题仍可在后续版本深化 |
| P0-2 答案键泄漏 | 采纳并关闭 | 新增 `PublicTask` 类型；SUT 看不到 target/forbidden/evidence；策略与 grader 分离；加入目标噪声化测试 | 真实 provider adapter 尚未实现，这是明确的示例边界 |
| P0-3 空需求满分 | 采纳并关闭 | schema 禁止空 target 与空 required evidence；coverage 对空集合直接报错 | 业务 schema 仍需企业自定义字段 |
| P0-4 测试同义反复 | 采纳核心、调整门槛 | 从 6 个表面测试扩为 11 个语义测试，覆盖答案隔离、目标噪声、替代路径、近错、veto、schema、真实 trial 方差；内容门禁检查来源、模板镜像、错链与正文下限 | 未实现“mutation score ≥90%”；该数值不是天然有效标准，应按命名失效模式继续补测试 |
| P0-5 伪重复 | 采纳并关闭 | seed 贯通四类故障；每格 4 trial；比较先在任务内汇总，再对 10 个任务配对 bootstrap，输出 `paired_tasks`、总 trial 和 95% 区间 | 示例 bootstrap 是教学实现，不替代复杂相关结构模型 |
| P0-6 两条错链 | 采纳并关闭 | SWE-Skills-Bench→2603.15401；SupChain-Bench→2602.07342；另把 RetailBench 切到规范 2603.16453 | 自动联网题名比对为维护命令，不放进每次离线构建 |
| P0-7 原始 TeX | 采纳并关闭 | 按 VitePress 官方方法加入 `markdown-it-mathjax3` 与 `math: true`；修正行内分隔符；构建后检查 HTML 无 TeX 残留且有 MathJax | 依赖链继承 VitePress 1.6.4 的开发依赖安全告警，见验证记录 |
| P0-8 固定结构/证据标签 | 调整采纳 | 阅读指南改为统一学习元素而非六个机械标题；对来源事实、综合判断、实践建议、未来推测加入可见容器；补案例答案 | 不强制每章出现相同六段，避免形式大于教学目的 |
| P0-9 来源账本 | 部分采纳 | 全部 140 个正文外链都进入本地账本；6 个高风险一手来源补作者、版本、访问日和 `verified_primary`；其余 134 条显式保留 `unverified`；新增离线 schema 与可选联网健康检查 | 未完成 134 条元数据逐条核验，不能宣称全部证据已审定 |
| P0-10 零图 | 调整采纳 | 新增 3 张有 title/desc/alt 的核心关系图：SUT—协议、Skill 行为链—实验条件、企业四层证据 | 不接受“每章一图”作为 P0；只在关系确实难以用短文说明时作图 |
| P0-11 零文献实测数字 | 部分采纳 | 第 10 章加入 SkillsBench 与 SWE-Skills-Bench 的任务数、配置数、通过率、增益、负迁移与 token 开销，并明确外推边界 | 不强制每章三组数字；历史/概念章不应为过门禁硬塞指标 |

## 当前发布判断

**内部课程与 public beta：Go。** 原 v0.1 的六个 Major 中，错链、公式、SUT/grader 因果污染、案例定位、答案支架和 Radar 口径已实质改善。

**“所有来源均经学术级核验的 v1.0 权威教材”：仍是 No-Go。** 主要残余是 134 条来源元数据未逐条核验、关键历史/项目主张尚未普遍达到 claim-level 引文，以及公平/数据劳动治理/在线人机评测等横切专题深度不足。它们被明确保留为证据不足，而不是用本轮大量工程修复掩盖。
